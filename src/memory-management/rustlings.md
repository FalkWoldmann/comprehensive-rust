# Exercise: Rustlings

This segment has no exercise of its own. Practice ownership and moves with the
matching [Rustlings](https://rustlings.rust-lang.org/) exercises:

- `vecs1`
- `move_semantics1` to `move_semantics3`

These exercises use `Vec<i32>`, a growable array of `i32` values that lives on
the heap. Like `String`, a `Vec` is moved on assignment and when it is passed to
a function.

<details>

- `Vec` is covered in detail in the Standard Library Types segment. For these
  exercises students only need `vec![1, 2, 3]` to create one and `push` to
  append to it, both of which appear in the exercise code.

- `move_semantics4` and `move_semantics5` need references and follow in the next
  segment.

</details>
