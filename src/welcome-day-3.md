# Welcome to Day 3

We have now seen all the core language features:

- **Foundations:** Basic types, control flow, and functions.
- **Ownership and Borrowing:** Moves, references, and the borrow checker.
- **User-Defined Types:** Model data with `struct` and `enum`, and destructure
  it with pattern matching.
- **Polymorphism:** Methods, Traits, and Generics.
- **Standard Library:** Using essential types like `Option`, `Result`, `Vec`,
  and `String`.
- **Closures:** Anonymous functions that can capture their environment.

You can write any type and associate behavior with it. Today we look at the
traits the standard library builds on and at error handling, and then return to
ownership and borrowing with everything we have learned since day 1.
